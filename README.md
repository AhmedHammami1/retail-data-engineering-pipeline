# Retail Data Engineering Pipeline & Data Warehouse

## 📌 Project Overview

This project aims to design and implement an end-to-end Data Engineering pipeline for a retail business.

The objective is to collect, extract, transform, validate, and load retail data into a PostgreSQL Data Warehouse to support analytical queries and business intelligence.

## 🎯 Project Objectives

- Build an automated ETL pipeline.
- Extract data from different sources.
- Clean and transform data using Python and Pandas.
- Design and implement a PostgreSQL Data Warehouse.
- Develop efficient SQL queries for analytical purposes.
- Containerize the application using Docker.
- Apply professional software engineering and Git practices.

## 🛠️ Technologies

| Technology | Purpose |

| Python | ETL development |

| PostgreSQL | Data Warehouse |
